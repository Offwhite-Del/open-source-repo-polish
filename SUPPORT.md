# Support / 获取帮助

Use the repository Issue forms for reproducible defects and bounded feature requests. Remove credentials, private paths, repository data, transcripts, plans, backups, and receipts before posting.

可复现缺陷和范围明确的功能建议请使用仓库 Issue 表单；提交前删除凭证、私人路径、仓库数据、会话、计划、备份和回执。

Security issues must use [private vulnerability reporting](https://github.com/Offwhite-Del/open-source-repo-polish/security/advisories/new). / 安全问题必须使用[私密漏洞报告](https://github.com/Offwhite-Del/open-source-repo-polish/security/advisories/new)。
