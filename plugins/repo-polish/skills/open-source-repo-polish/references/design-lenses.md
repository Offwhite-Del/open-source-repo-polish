# Design lenses

Use these as questions, not as a combined brand style. The repository's purpose and existing identity remain authoritative.

## Distinctive purpose

Derived from Anthropic's public `frontend-design` guidance:

- Name the intended tone before designing: calm technical instrument, editorial reference, industrial utility, playful learning tool, or another project-specific direction.
- Make one element memorable. Do not make every element loud.
- Avoid the default AI-repository combination of purple gradients, generic glass cards, excessive badges, and interchangeable copy.
- Match execution complexity to the idea. Refined minimalism requires exact spacing and hierarchy, not decorative effects.

Primary reference: <https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md>

## Technical warmth

Derived from OpenAI's public design guidance:

- Balance technological precision with approachable language and humane curves.
- Use geometry consistently; do not mix unrelated radii, line weights, icon styles, or illustration systems.
- Leave deliberate clear space around identity elements.
- Do not use OpenAI names, wordmarks, the Blossom, proprietary fonts, or other brand assets to imply affiliation.

OpenAI's page is a brand guide, not a general repository-design system. Treat the ideas above as limited visual inspiration and the trademark restrictions as hard boundaries.

Primary reference: <https://openai.com/brand/>

## Calm hierarchy

Derived from Apple's Human Interface Guidelines and the local Apple design reference:

- Establish hierarchy, harmony, and consistency before adding styling.
- Prefer familiar GitHub conventions for navigation, installation, issues, and contribution.
- Keep the user in control: separate read-only audit from mutation and preserve rollback paths.
- Use restrained color, sufficient contrast, accurate alternative text, and layouts that survive narrow screens and light/dark themes.
- Static README files do not benefit from gesture or spring guidance. Apply motion principles only to real interactive pages and respect reduced motion.

Primary reference: <https://developer.apple.com/design/human-interface-guidelines>

## Synthesis rule

When the lenses conflict:

1. truth and accessibility win;
2. project identity wins over borrowed aesthetics;
3. platform familiarity wins over novelty for functional controls;
4. distinction wins only where it improves recall without slowing comprehension.
