# Code of Conduct / 行为准则

Be respectful, specific, and evidence-oriented. Critique ideas and implementations, not people. Harassment, discrimination, threats, deliberate disruption, sexualized attention, and disclosure of private information are not accepted.

请保持尊重、具体并以证据为依据；讨论观点和实现，不攻击个人。项目不接受骚扰、歧视、威胁、蓄意干扰、性化关注或泄露私人信息。

Report conduct concerns privately through the maintainer contact on the repository owner's GitHub profile. Maintainers may remove content or restrict participation when necessary.

请通过仓库所有者 GitHub 主页上的维护者联系方式私下报告行为问题。维护者可在必要时移除内容或限制参与。
