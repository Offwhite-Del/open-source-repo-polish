# Contributor guidance

- Preserve evidence before presentation: never invent metrics, compatibility, badges, testimonials, or maintenance claims.
- Keep the audit local-only, read-only, zero-telemetry, and dependency-free at runtime.
- Treat design references as lenses, not brand templates; do not copy third-party logos, fonts, or protected assets.
- Keep deterministic checks in the script and tests; keep contextual judgment in the Skill.
- Update English and Simplified Chinese user-facing documentation together.
- Run tests, Skill validation, plugin validation, link checks, render checks, and a secret scan before release.
